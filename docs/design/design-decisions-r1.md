# Running Light - Design decisions, revision 1 (approved by Rogin 2026-10-22)
1. Gamble: player PICKS red or white before each flip (fair 50/50), then reveal. Redesign mockup 05 and gamble components accordingly.
2. Collect/Gamble stay in right panel as designed; flip modal only for the gamble itself.
3. Keys: G = Gamble, Enter = Collect; add R/W (or arrow keys) for the red/white pick.
4. Tooltip per-round odds incl. Double Run plus per-stop odds in paytable: OK.
5. No Reset credits. 6. No Rebet x2. 7. No tutorial in v1.
8. Free refill: no limit, no cooldown (play credits only).
9. Confetti/sparks, no coins: confirmed.
10. Last Win showing uncollected win during gamble offer: intended.
11. Double Run = ONE history entry showing both squares. Update history strip in mockups 04 and component sheet 2.
12. Show RTP about 95.45% in the paytable modal (08b).
13. Squares lock (non-interactive) while the light runs; visually mark locked state subtly without hiding the lit bulbs.
